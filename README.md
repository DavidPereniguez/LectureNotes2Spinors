# LectureNotes2Spinors

This repository contains personal lecture notes on gravitational 2-spinors, together with example Mathematica notebooks illustrating some of the computations. The notes are based on a 6-hour PhD course I gave at the University of Perugia in April 2025.

## Contents

Lecture notes in PDF format:

- `Notes.pdf`

Example Mathematica notebooks:

- `Example1.nb`
- `Example2.nb`

## Description

- **Example1.nb** obtains exact curvature wave equations for the Weyl scalars starting from the 2-spinor wave equations. It also derives the linearised Teukolsky equations on a type D background.

- **Example2.nb** describes the Kerr geometry in the GHP formalism using explicit expressions in local coordinates and null frames.

## Requirements

- Wolfram Mathematica  
- xAct package suite (available at https://www.xact.es/)  
- `diffgeo.m` (available at https://github.com/bryango/diffgeoM)

## Usage

1. Install Mathematica, the xAct packages, and `diffgeo.m`.  
2. Open the notebooks and evaluate the cells sequentially as indicated.

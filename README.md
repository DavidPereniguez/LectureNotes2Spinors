# LectureNotes2Spinors

This repository contains personal lecture notes on gravitational 2 spinors, together with example Mathematica notebooks illustrating some of the computations. The notes are based on a 6h PhD course given at the University of Perugia in April 2025. 

## Contents

* `notes/`
  Lecture notes in PDF format.

* `code/`
  Example Mathematica notebooks:

  * `Example1.nb`
  * `example2.nb`

## Description

The notebook Example 1 obtains exact curvature wave equations for the Weyl scalars starting from the 2-spinor wave equations. It also obtains the linearised Teukolsky equations on a type D background.

The notebook Example 2 describes the Kerr geometry in GHP language using explicit expressions in local coordinates and null frames.

## Requirements

* Wolfram Mathematica
* xAct package suite (available at https://www.xact.es/)
* diffgeo.m (available at https://github.com/bryango/diffgeoM)

## Usage

1. Install Mathematica, the xAct packages and diffgeo.m.
2. Open the notebooks in the `code/` directory.
3. Evaluate the cells sequentially as indicated in the notebook.
